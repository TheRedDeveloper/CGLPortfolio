Ply Engine

200+ GitHub stars, released this month

Ply is an engine written in pure Rust. It compiles to 6+ platforms from a single codebase with no platform-specific code required.

Dead Simple API Builder pattern with closure-based children, minimal boilerplate.
Cross-Platform Web, desktop, Android, iOS and more. One codebase, no platform-specific code.
Accessibility AccessKit integration and JS bridge. Screen reader and keyboard support built in.
GPU Shaders GLSL shaders, rotation and built-in effects via hardware acceleration.
Layout Engine Flexbox-like layout: padding, gaps, grow, fit, scroll, floating...
Text Selection, undo/redo, multiline, styled text, virtual keyboards...
Debug Inspector Browser DevTools-like view built directly into the engine.
Vector Graphics Custom TVG renderer with multi-step GPU caching.
Interactive Docs Live, editable code examples in the browser and custom interpreter.

Stratum

A two-player abstract strategy game built on Ply. Players compete to form a connected path across opposite edges of the board using Roads, Walls, Towers and Charms.

Moderation stack
  • 0. A table of 5 Charms is shown. A 3-second countdown begins, after which both players pick up to 2. The player who takes the last Charm goes first.
  • 1.
    The active player does one of:
    • Place a Road, Wall or their single Tower on any empty space.
    • Move a single piece to any adjacent tile with <5 stones, or move a stack in a straight line, dropping pieces one by one. The Tower is the only piece that can move onto a Wall, which flattens it.
    • Use one of their Charms.
  • 2. Gems are tallied. If an orthogonally connected path of uncovered Roads and Towers links any two opposite board edges, the active player wins. If the board is full with no path, most Gems wins. Turns then alternate.
  • -1. The Shop sells Charms for Gems earned across matches.
  • 0. Before starting, the player picks 2 Charms from their collection.

ed25519fast

ed25519fast is my Ed25519 elliptic curve cryptography implementation written in Rust (CPU) and Slang (GPU). It is the fastest known secure implementation of digital signature cryptography and 3-30x faster in most cases.

Accessibility

I think games that exclude people with disabilities are a failure of imagination. Every app on Ply gets full screen reader support, across all 6+ platforms using the respective screen readers. Stratum inherits this without much extra work.

Play Stratum

This demo drops you straight into Level 3, against an early Purist with 40% imperfection.

// what's happening
▸Each turn you place one piece, move one, or use a Charm.
▸First to connect two opposite edges of the board with an unbroken path of their Roads and Towers wins.
▸If the board fills with no path, the player with more Gems wins.
▸The Swap charm lets you exchange any two tiles on the board.
▸7 more charms are already balance-tested and implemented each allowing for unique strategies.
